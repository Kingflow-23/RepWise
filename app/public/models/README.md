# Studio figure

`studio-figure.glb` is the **Male base mesh — 3D Person, Rigged A-pose**,
created by Innerscene from MakeHuman CC0 assets. The source explicitly releases
the model under CC0, allowing modification and redistribution.

- Source and licence declaration: https://www.innerscene.com/tools/library/3d-parts/male-base-mesh-3d-person-rigged-a-pose-380e6d89

- CC0 terms: https://creativecommons.org/publicdomain/zero/1.0/

RepWise supplies its own graphite material and studio lighting at runtime.
The figure is a visual reference, not an anatomical diagnosis, exercise
demonstration, or representation of the signed-in user's body.
